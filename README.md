# Консольное приложение определения скорости сети на python 3.13

Скрипт последовательно выполняет серию get-запросов к сетевому ресурсу


## Установка

> [!WARNING] Перед использованием требуется установка зависимостей:

```bash
pip install -r requirements.txt
```

## Использование

```bash
python main.py --url [URL] --num_requests [INTEGER]
```

Где: 

`url` - URL адрес скачиваемого, (по умолчананию `https://esahubble.org/media/archives/images/publicationtiff/sci25007a.tif`)

`num_requests` - число выполняемых запросов на скачивание, (по умолчанию `10`)

Скрипт можно запустить с параметрами по умолчанию (заданы в модуле src/app/parser.py):

```bash
python main.py
```
